A look inside

How it works

No sign-up. Your data lives in a private GitHub repository that only you control.

Make a private repository

A free GitHub account and one empty private repository. The app fills it in the first time it connects.

Create an access key

The setup screen walks you through a key that can only touch that one repository.

Add it to your home screen

In Safari tap Share › Add to Home Screen. It opens instantly and works offline.

Privacy

  • Everything you log is saved in your own private GitHub repository, plus a copy on each connected phone so it works offline.
  • The app only talks to this website (to load itself) and to GitHub (to read and save your data with your key).
  • The app has no server of its own and collects nothing: no analytics, ads or cookies. I made it, and I can't see your data either.
  • Your access key stays on your phone. Setup links keep it after the #, which browsers never send anywhere, and the app wipes it from the address straight away.
  • To remove everything, disconnect in Settings, then delete the key and the repository on GitHub.

Questions

Does it cost anything?

No. GitHub's free account is enough.

Does it only work on iPhone?

It's designed for iPhone, but it runs in any modern browser, including Android and desktop.

Is it veterinary advice?

No. It's a tracking tool. Run food changes past your vet, especially with prescription diets.

Can I use it for my own two cats?

Yes, as long as you don't mind them being called Albert and Milly for now: plans, foods, birthdays and photos are all yours to set, but the names are built in. The code itself isn't open source; see the licence.
